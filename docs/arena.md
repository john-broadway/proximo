# The arena

Every address the four Proxmox products publish, by the verdict the engine gives it to an
armed operator. Generated by `scripts/arena.py`; `tests/test_arena.py` refuses a stale copy
and refuses a published mutation with no verdict at all.

| class | total | pve | pbs | pmg | pdm |
|---|---|---|---|---|---|
| reads served | 884 | 322 | 172 | 192 | 198 |
| mutations open to an armed operator (tiered) | 785 | 308 | 165 | 199 | 113 |
| opened by an operator switch, judged like any mutation (guest agent, container and node shell) | 32 | 32 | 0 | 0 | 0 |

| excluded: not a JSON call (protocol upgrades, console tickets, a deprecated alias) | 78 | 16 | 22 | 29 | 11 |
| **every published address** | **1804** | 685 | 367 | 425 | 327 |

## Held: refused on purpose

A held line is a judgement with a sentence, read by `govern()` before arm. Opening one is a
line moved from `[tier.held]` to `[tier]` in `tiers.toml`, John's hand by name.

- `pbs:DELETE /access/ticket`: Ends a login-ticket session the door never minted; the door dials with its own token and holds no ticket to end.
- `pbs:POST /access/openid/auth-url`: Starts an OpenID login the door cannot finish: the vendor returns a redirect URL for a browser, and the ticket it would end in is a session credential usable outside the door, around every pillar.
- `pbs:POST /access/openid/login`: Exchanges an OpenID authorization code for a login ticket, a session credential the caller could use outside the door, around every pillar; the door dials with its own token and needs no ticket.
- `pbs:POST /access/ticket`: Logs in with a password the caller supplies and hands back a ticket and CSRF token, a session credential usable outside the door, around every pillar; the door dials with its own token and needs no ticket.
- `pbs:POST /access/vncticket`: Verifies a VNC console ticket, the credential behind an interactive console the door does not open; a console is a shell outside every pillar.
- `pdm:DELETE /access/ticket`: Ends a login-ticket session the door never minted; the door dials with its own token and holds no ticket to end.
- `pdm:POST /access/openid/auth-url`: Starts an OpenID login the door cannot finish: the vendor returns a redirect URL for a browser, and the ticket it would end in is a session credential usable outside the door, around every pillar.
- `pdm:POST /access/openid/login`: Exchanges an OpenID authorization code for a login ticket, a session credential the caller could use outside the door, around every pillar; the door dials with its own token and needs no ticket.
- `pdm:POST /access/ticket`: Logs in with a password the caller supplies and hands back a ticket and CSRF token, a session credential usable outside the door, around every pillar; the door dials with its own token and needs no ticket.
- `pdm:POST /auto-install/answer`: Answers an installing machine's request for its answer file, root password in plain text and the subscription key with it: the door's caller is never the installing machine, and the answer is a credential set for a machine that is not the caller; held until John opens it by name.
- `pmg:POST /access/oidc/auth-url`: Starts an OpenID login the door cannot finish: the vendor returns a redirect URL for a browser, and the ticket it would end in is a session credential usable outside the door, around every pillar.
- `pmg:POST /access/oidc/login`: Exchanges an OpenID authorization code for a login ticket, a session credential the caller could use outside the door, around every pillar; the door dials with its own token and needs no ticket.
- `pmg:POST /access/ticket`: Logs in with a password the caller supplies and hands back a ticket and CSRF token, a session credential usable outside the door, around every pillar; the door dials with its own token and needs no ticket.
- `pmg:POST /access/vncticket`: Verifies a VNC console ticket, the credential behind an interactive console the door does not open; a console is a shell outside every pillar.
- `pve:POST /access/openid/auth-url`: Starts an OpenID login the door cannot finish: the vendor returns a redirect URL for a browser, and the ticket it would end in is a session credential usable outside the door, around every pillar.
- `pve:POST /access/openid/login`: Exchanges an OpenID authorization code for a login ticket, a session credential the caller could use outside the door, around every pillar; the door dials with its own token and needs no ticket.

- `pve:POST /access/vncticket`: Verifies a VNC console ticket, the credential behind an interactive console the door does not open; a console is a shell outside every pillar.
- `pve:POST /cluster/config/nodes/{node}`: Adds a node to the cluster configuration, a call the vendor marks for internal use, and answers with the corosync authkey, the secret that admits a node to the cluster; held until John opens it by name.
- `pve:POST /nodes/{node}/execute`: Runs a JSON array of API calls in one request, root only: the inner addresses and methods never pass through resolve, tier, forbid or scope, so one grant here would open every other address through it; held until each inner call is governed as itself.

## The download lane

A byte stream, not JSON: the bytes land under `PROXIMO_RESTORE_DIR` in a fresh private directory,
capped by `PROXIMO_RESTORE_MAX_BYTES`, and the answer carries the path, the count and the sha256.
Opt-in: `PROXIMO_ENABLE_DOWNLOAD=1`. The raw GET door still refuses them (it answers JSON).

- `pbs:GET /admin/datastore/{store}/download`
- `pbs:GET /admin/datastore/{store}/download-decoded`
- `pbs:GET /admin/datastore/{store}/pxar-file-download`
- `pmg:GET /quarantine/download` (untrusted bytes)
- `pve:GET /nodes/{node}/storage/{storage}/file-restore/download`

## Excluded: not a JSON call

- 34: protocol upgrade (websocket, backup and reader protocols, migration tunnels)
- 27: deprecated alias (pmg `/config/whitelist` = `/config/welcomelist`, which is served)
- 17: console ticket (a POST that mints the credential for an interactive console)
